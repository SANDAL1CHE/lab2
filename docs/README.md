# Документация проекта rectangle
---
## Общее описание решения
Библиотека для вычисления **площади** и **периметра** прямоугольника

---
## Описание функций
### Функция area(a, b)
Получает на вход 2 числа, выводит площадь
**Пример:**
```python
from rectangle import area
s = area(2, 3)
print(s) #выводит 6
```

---
### Функция perimeter(a, b)
Получает на вход 2 числа, выводит периметр
**Пример:**
```python
from rectangle import perimeter
s = perimeter(2, 3)
print(s) #выводит 10
```
